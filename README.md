# JONITA BOTS

Panel inicial para administrar asistentes/bots desde una interfaz adaptable a celulares.

## Estado actual
- Alta de bots con nombre, personalidad e instrucciones.
- Selección de modo de participación previsto.
- Activar, pausar y eliminar bots en el panel.
- Los datos de esta primera versión se guardan localmente en el navegador.

## Importante
Esta versión es una maqueta funcional local. **Todavía no conecta WhatsApp, no registra números y no envía ni recibe mensajes.** La integración real requiere un backend seguro y una conexión compatible con las políticas de WhatsApp/Meta. No se deben guardar tokens ni credenciales en el navegador.
